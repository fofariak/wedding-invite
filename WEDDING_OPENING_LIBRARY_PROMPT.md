# Mandap.co — Complete Religious and Traditional Wedding Invitation Opening Library

## 1. Your Task

I want to add a premium feature to Mandap.co called:

**Wedding Invitation Opening Library**

This feature will allow customers to choose how their digital wedding invitation begins.

Different families follow different religious, cultural and personal traditions. We want to provide a beautiful collection of traditional opening phrases, prayers, mantras, shlokas and scripture verses.

Support these categories:

1. Hindu
2. Muslim
3. Christian
4. Jain
5. Sikh
6. Universal / Minimal

The experience should feel like selecting a professional wedding invitation design, not selecting text from a dropdown.

Integrate this feature into the existing invitation editor.

First inspect the current project and explain your implementation plan. Do not break or replace existing functionality.

# 8. Design and User Experience

This feature must look premium.

Do not display the options as a plain dropdown list.

Build a visual selection interface.

### Step 1: Choose Tradition

Show beautiful category cards:

- Hindu
- Muslim
- Christian
- Jain
- Sikh
- Universal / Minimal

### Step 2: Choose Subcategory

For example, if a customer chooses Hindu, show:

- Ganesh
- Shiva–Parvati
- Vishnu–Krishna–Ram
- Lakshmi–Devi
- Swaminarayan
- Arya Samaj / Vedic
- General Traditional

If the customer chooses Muslim, show:

- Bismillah
- Quranic Verses
- Nikah Duas
- Urdu Openings

If the customer chooses Christian, show:

- Traditional
- Catholic
- Protestant
- Bible Verses
- Wedding Blessings

### Step 3: Choose Opening Design

Display multiple visual design cards.

Each card should show:

- The actual phrase or verse.
- Typography.
- Decorative design.
- Background.
- A clear selection indicator.

Customers should be able to preview each option before selecting it.

### Step 4: Live Invitation Preview

When the customer selects an opening:

- Display it immediately in the live invitation preview.
- Show the selected opening on the final hosted invitation website.
- Preserve all line breaks.
- Ensure the opening looks correct on mobile and desktop.

### Step 5: Customisation

Where supported by the design, allow customers to customise:

- Text colour.
- Font style.
- Font size.
- Alignment.
- Background.
- Decorative elements.

Do not allow customisation that breaks the layout or makes religious text difficult to read.
